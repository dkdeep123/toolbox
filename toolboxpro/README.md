# ToolBoxPro

A responsive, ad-ready free tools website MVP.

## Run
Open `index.html` directly in a browser, or serve the folder:
`python -m http.server 8000`

Then open `http://localhost:8000`.

## Monetization
This version contains non-intrusive placeholder ad slots. Before production, replace the placeholder with your approved Google AdSense ad code and publish Privacy Policy/Terms/Contact pages.
