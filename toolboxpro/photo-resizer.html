Frequently Asked Questions

How does the Target File Size (KB) feature work?
When you specify a target file size (e.g., 20 KB or 50 KB), ToolBoxPro uses an intelligent binary-search compression algorithm to calibrate JPEG quality until the resulting output falls within your exact size threshold.
Are the exam presets guaranteed to match my specific exam portal?
The included presets (such as SSC/UPSC Photo 350x450 and Signature 280x120) are common reference guidelines. Because official notifications can change, they are provided as convenient starting points that you can adjust to match your specific exam guidelines.
Is aspect ratio preserved when resizing?
Yes. The aspect ratio lock is enabled by default so changing width automatically scales height proportionally. You can unlock it anytime to enter arbitrary width and height values.
Why do application portals reject signature images?
Common reasons include: file size being over 20 KB or 50 KB, incorrect image dimensions, or uploading in an unsupported format like PDF instead of JPG/JPEG. ToolBoxPro solves all three by providing exact dimensions, target KB sizing, and clean JPG export.
